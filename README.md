# 多元表現小幫手｜高中・體育班

[開啟多元表現小幫手](https://lrw-crypto.github.io/student_c1/)

給高中生與體育班學生使用的多元表現編輯器。支援 F 至 N 與自訂類別，運動項目可選撐竿跳、鉛球、短跑、其他田徑項目，也可自行輸入。

1. 選活動類別及運動項目，填上成果標題。
2. 用點選或自述寫下做法、調整、實際成果與下一步。可載入撐竿跳、鉛球、短跑或接力範例看寫法。
3. 加入照片與圖說，在預覽確認兩欄版面，再下載 A4 PDF 或可編輯的 Word（.docx）。

草稿與照片儲存在目前的瀏覽器，檔案在裝置上產生。PDF 使用圖像式排版。共用電腦使用完畢後，可下載交件檔案並使用「清空草稿」。

## 本機開發

在倉庫根目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。網站使用原生 HTML、CSS 與 JavaScript。GitHub Pages 從 `main` 根目錄部署。
