# 多元表現小幫手｜高中・體育班

[開啟多元表現小幫手](https://lrw-crypto.github.io/student_c1/)

給高中生與體育班學生使用的多元表現編輯器。支援 F 至 N 與自訂類別，運動項目可選撐竿跳、鉛球、短跑、其他田徑項目與常見運動。

1. 點選運動項目和活動類別。
2. 點選做法、困難、成果及下一步。標題和內文會隨選項更新。可載入撐竿跳、鉛球、短跑或接力範例看操作方式。
3. 可加入照片並點選圖說，確認兩欄版面後，下載 A4 PDF 或可編輯的 Word（.docx）。

姓名、自述和定稿修改放在選填區。學生可全程點選完成，不需輸入文字。草稿與照片儲存在目前的瀏覽器，檔案在裝置上產生。PDF 使用圖像式排版。

## 本機開發

在倉庫根目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。網站使用原生 HTML、CSS 與 JavaScript。GitHub Pages 從 `main` 根目錄部署。
